# LangChain Certified Agent Engineer — Practice Repo

My hands-on learning journey through Python fundamentals and LangChain 
concepts while preparing for the LangChain Certified Agent Engineer (LCAE) 
certification.

## What's in here
- Python OOP practice (classes, inheritance, class/instance variables, 
  static/class methods)
- LangChain fundamentals (chat models, tool calling, agents)
- Daily learning notebooks — real practice, not tutorials copy-pasted

## Setup
This project uses `uv` for dependency management.

\`\`\`bash
git clone https://github.com/aftabhussa/LangChain-Certified-Agent-Engineer-Practice.git
cd LangChain-Certified-Agent-Engineer-Practice
uv sync
\`\`\`

You'll need your own `.env` file with an `OPENAI_API_KEY` to run the notebooks.
